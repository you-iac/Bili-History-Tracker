# 点赞、投币、收藏视频的查看与自动关注

- 创建时间：2026-11-24 20:30（Asia/Shanghai）。
- 状态：待实施；本项先完成文档与接口调研，不修改业务代码。
- 依赖：本地 Cookie、`library.Follow`/`Submit`、后台循环任务。

## 目标

1. 查看当前账号点赞、投币、收藏的视频；
2. 与本地关注/记录去重，支持手动关注；
3. 设置开启自动关注后，后台循环增量发现新历史，并对历史条目按 TTL 重查互动状态，自动关注有互动的视频；
4. 复用 `Follow`/`Submit` 推送服务器。

## 数据来源（已实测）

| 来源 | 接口 | 说明 |
|---|---|---|
| 收藏 | `/x/v3/fav/folder/created/list-all` + `/x/v3/fav/resource/list` | 已确认可用，分页拉全部收藏夹内容 |
| 点赞 | `/x/web-interface/archive/has/like?bvid=` | 单视频返回 0/1 |
| 投币 | `/x/web-interface/archive/coins?bvid=` | 返回 `data.multiply`，0/1/2 表示用户投币数 |

- 点赞/投币没有公开的完整列表接口，只能对已知历史视频逐条查询；
- 转发暂不支持（未确认接口，需求先不做）；
- 所有请求需要登录态 Cookie。

## 增量发现

```text
每轮同步
  → 拉历史最新一页（30 条）
  → 与本地按 bvid 去重
  → 新增条目：立即查互动
  → 已存在条目：不做全量重查，按下面的 TTL 处理
  → 当前页大量已存在且时间旧 → 停止继续翻页
```

停止条件：

- 本页新增数量低于阈值（如 0–2 条）；或
- 本页最旧 `viewed_at` 超过上次同步位置。

## 互动状态重查（TTL）

每条历史记录保存：

```text
interaction_checked_at   上次查询互动的时间
like / coin / favorite   已发现的互动状态
```

重查规则：

```go
if now.Sub(item.InteractionCheckedAt) >= ttl { 重查 }
```

- 最近 3 天的记录：TTL 6 小时；
- 3–30 天的记录：TTL 24 小时；
- 每轮最多查 60 条，按 `interaction_checked_at` 最旧优先；
- 新增条目优先于重查；
- 已关注条目不再查互动。

这样“看了视频、后来才点赞”最迟一个 TTL 被发现。

## 自动关注

```text
有互动（like=1 或 coin>0 或 favorite=true）
  且未关注
  → library.Follow（本地 + 服务器 Submit）
  → 打 auto 标记
```

- 每来源/每轮上限 20 条；
- 失败进待重试队列；
- 自动关注可批量撤销；
- 关闭开关后停止。

## 设置

- 自动关注开关；
- 来源勾选：点赞 / 投币 / 收藏；
- 检查频率：30 分钟 / 1 小时 / 6 小时；
- TTL：固定 6h/24h，或后续可配；
- 只自动关注最近 N 天（默认 30 天）。

## 边界

- 互动数据只存本地；
- Cookie 不出本机；
- 推送服务器复用 `Follow`/`Submit`，不新增接口；
- 转发暂不做；
- 不自动取消关注；
- 风控/限流退避。

## 验收

- 历史增量发现不会每次全量翻页；
- 新增条目立即查互动；
- 旧条目按 TTL 重查，点赞后能发现；
- 有互动且未关注 → 自动关注并推送；
- 转发不参与；
- 去重、预算、失败队列生效；
- 测试通过。
