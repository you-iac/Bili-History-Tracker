## 背景与现状

当前 Agent 添加关注时先保存本地，再提交服务器；未确认的申请通过 `RunPending` 自动重试，失败按1、2、4、8、15分钟退避，但没有终止上限。已确认目标不会被周期核对，因此服务器后来丢失任务时，Agent 不会自动补申请。资料摘要同步只解决卡片显示，不代表跟踪状态已经一致。

后台已提供 `GET /api/targets/status?kind=...&id=...` 和 `POST /targets`，能区分已记录、正在跟踪和明确暂停，并对重复申请复用已有任务。但部分上游失败在提交接口中统一返回一般错误，Agent 无法准确区分下架、权限限制、平台风控等原因。

## 目标与边界

1. 个人关注表示用户意愿，与申请投递、服务器公共任务、内容可用性分别记录和显示；不得把本地保存成功或资料可读取当作服务器已跟踪。
2. 默认自动核对并按需补申请，手动“立即核对”“重试申请”作为补充；不要求用户逐个发现漏跟踪。
3. 只针对当前配置的服务器执行。虚拟机与云服务器独立，不双写、不自动复制测试状态；切换服务器后重新核对并拒绝旧来源请求写回。
4. 不自动认定视频已下架，不将采集异常改成零播放量或空内容，不删除关注、缓存或历史。
5. 不调整后台采集频率，不代替管理员恢复已暂停任务，不向服务器上传平台 Cookie、私人档案或媒体。

## 实施方案

### 状态与判断

保留本地关注、申请结果、最近确认的公共任务状态、核对时间和重试调度信息。状态至少能表达待核对、待申请、已确认、服务器暂停、暂不可达及需要手动处理；兼容已有 `pending_submission`、`remote`、提交次数和退避时间，不将摘要刷新时间当成任务核对时间。

| 本地关注 | 服务器任务 | Agent 处理 |
|---|---|---|
| 是 | 确认已启用 | 更新确认时间，结束待提交状态，复用任务，不重复要求立即采集 |
| 是 | 确认未创建且未明确暂停 | 自动补申请，收到确认才标记成功 |
| 是 | 明确暂停 | 保留关注，停止自动申请并说明原因；状态只读核对可继续 |
| 是 | 已启用但最近采集异常 | 任务仍视为已存在，展示异常或原因未确认，不反复新建申请 |
| 是 | 查询失败或断连 | 保留最近已知状态并标注未知/过期；恢复后先核对，不能当作任务不存在 |
| 否 | 任意 | 不新增申请、不恢复本地关注；服务器已有公共任务和历史由服务器管理 |

没有首次历史且申请失败时保留个人关注和失败说明；已有历史但当前采集异常时继续展示最后记录。仅有一般失败信息时显示“原因未确认”，不解析中文错误消息来推断永久拒绝或下架。

### 自动核对与幂等申请

- 启动、服务器连接恢复、切服及周期任务触发核对；分页/分批处理本地目标，设置并发、每轮数量和核对间隔上限，避免每次页面渲染都请求全库。
- 已确认目标也定期复核；服务器恢复旧数据库或丢失任务后，仍关注的目标可重新申请。
- 提交前先查精确状态。提交超时后也先查询确认，防止服务器实际已接受时仍无意义地重复申请。
- 同目标合并在途核对/提交，复用现有服务器去重行为。响应写回核对服务器代际及原关注身份，切服、取消关注和取消后重新关注均不接受旧操作结果。
- 网络查询失败不作为明确拒绝。明确暂停停止自动申请；可确认的忙/限流采用退避。无法细分的连续申请失败设置次数上限和冷却，转为需要手动处理，并保留失败原因及下次允许重试时间。
- 本地重试限制只影响申请协调，不暗示服务器停止采集。手动重试应先重新核对状态，不能绕过服务器暂停。

### 展示与持久化

- 正常库卡片继续精简，不重新堆叠公共跟踪和采集状态；库提示、管理菜单及详情提供异常说明和手动入口。
- 明确展示最近核对时间、待处理原因及是否会自动重试，区分“已本地关注”和“服务器已确认”。
- 状态和调度信息持久化到本地关注库，重启保留；旧数据安全升级，不把未知状态补成已确认或永久不可用。
- 文档同步当前能力、重试边界和后台接口限制；实现位置与测试入口更新到 [架构导航](../docs/architecture.md)。

## 验收条件

- 覆盖本地关注/未关注、远端已跟踪/未跟踪/暂停/未知及正常/采集异常的组合；状态核对不改变用户意愿。
- 已确认目标在服务器丢失后可被发现并补申请；重复核对、并发点击和超时后重试不产生额外跟踪任务或强制采集。
- 明确暂停不会循环提交；网络失败不会误判未跟踪；无法区分的连续失败最终进入有界冷却或人工处理状态，而非永久高频重试。
- 视频无法访问时保留本地关注与最后资料，不伪造下架原因、下架时间、零指标或空版本；不改变服务器调度。
- 切服（含切走再切回）、取消、重新关注、断连恢复和重启均不受旧请求污染；只协调当前服务器，不向云服务器传播虚拟机测试操作。
