# 已完成计划归档

本目录保存已经完成目标并通过必要验证的独立计划，文件名沿用原创建日期和主题。每项计划的顶部完成摘要记录当前状态、原创建时间、实际完成时间和验证结果；原方案及实施历史完整保留在下面。

未完成、部分完成或仍待验收的计划保留在 [PLANs/](../README.md)，不能只因正文含“已完成”字样就移入本目录。归档只移动整个文件并修正链接，不重置时间、不压缩正文，也不表示已重新执行历史验证。

本目录中的仓库文件链接使用 `../../` 起算；引用同目录归档计划使用文件名，引用活动计划使用 `../文件名.md`。完整流程见 [计划目录约定](../README.md#完成方式) 和 [仓库规则](../../AGENTS.md#计划记录与归档)。
