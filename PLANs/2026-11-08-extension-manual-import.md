# 扩展与手动导入（后续）

- 创建时间：2026-11-08 23:15（Asia/Shanghai）。
- 状态：待实施（后续增强）；交互、服务器融合、分页、重试与管理员归属以 [作者视频融合计划](archive/2026-11-08-creator-video-discovery.md) 和 [设计文档](../docs/video-discovery.md) 为准，本项只保留服务器无法直接发现时的补充入口。
- 目标：在服务器适配器可发现范围之外，提供浏览器扩展和手动粘贴两种补充方式；两者都只传视频 ID，不传 Cookie，由服务器用公开 `view` 接口校验归属、去重后入库。

## 范围

| 方式 | 凭据位置 | 说明 |
|---|---|---|
| 浏览器扩展 | 留在浏览器 | 在 B站空间页用用户登录态完整翻页，只提交 BV 列表；作为后续增强，不是首版必需 |
| 手动粘贴 | 无 | 用户从 B站复制 BV 或链接，服务器解析、校验、入库 |
| 本地 Agent | 留在本地 | 已独立列入 [客户端界面与本地 Agent](2026-11-10-client-agent.md) 计划；按需发现、本地关注、公共采集申请和本地备份见 [客户端设计](../client/README.md) |

- 服务器不接收 Cookie，不代持用户凭据。
- 两种方式优先复用现有 `POST /api/ingest/videos` 及任务结果；普通客户端接入时补准入与幂等，不继承管理权限，不默认再建重复提交路由，见 [8182 复用范围](../docs/client-server-architecture.md#复用-8182-远程能力)。
- 归属校验：`view` 接口返回的 `owner.mid` 必须等于目标作者，不符直接拒绝。
- 去重：分别核对公共记录与跟踪状态；已有跟踪直接复用，有记录未跟踪按策略恢复或拒绝，不补私人云端订阅，也不反复即时采集。
- 手动粘贴支持 BV 号、视频链接和混排文本，服务端提取并去重。

## 待确认

- 扩展与公共入口的服务准入方式：不依赖个人账户，不内置共享管理员密钥。
- 单次批量上限，以及每来源/安装凭据和全局的限流值。
- 扩展是否进入近期范围，还是先只做手动粘贴。

## 边界

- 扩展和手动导入只补充“服务器可发现范围之外”的视频，不承诺覆盖全部投稿。
- 不记录 Cookie 或请求头；失败只记录分类和非敏感原因。
- 批量导入失败可重试，已成功项不重复写入。
