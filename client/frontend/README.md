# 浏览器界面（规划）

状态：待实施。本目录用于浏览器界面，目前只有职责说明，尚无可运行代码。界面与本地 Agent 共用 [客户端需求与设计](../README.md)，模块关系见 [docs/architecture.md](../../docs/architecture.md#module-navigation)，实施计划见 [PLAN.md](../../PLAN.md)。

主要职责：

- 展示作者、视频、历史观测、发现规则、任务进度和本地文件状态，具体页面与操作见 [统一需求](../README.md#页面与操作)。
- 通过同源本地 HTTP API 向 [Agent](../agent/README.md) 提交配置和任务操作，读取校验结果与持久化状态；远端服务器和平台请求由 Agent 执行。
- 显示服务器离线、Agent 断连、凭据失效和任务失败等状态，刷新或关闭页面不取消 Agent 已接收的任务。

界面构建产物随 Agent 发布，由 Agent 提供网页访问入口；界面框架与构建方式在实施时确定，后续在本目录补充开发和构建约定。跨界面与后台的配置、凭据、执行流程及验收要求统一维护在上级文档。
