# 本地 Agent（规划）

状态：待实施。本目录用于本地后台程序，目前只有职责说明，尚无可运行代码。浏览器界面与后台共用 [客户端需求与设计](../README.md)，模块关系见 [docs/architecture.md](../../docs/architecture.md#module-navigation)，实施计划见 [PLAN.md](../../PLAN.md)。

Agent 运行在用户设备上，负责托管 [client/frontend/](../frontend/README.md) 的构建产物和同源本地 HTTP API。目录路径以仓库根目录为基准；需求、页面操作和验收统一维护在上级文档，本目录后续补充启动、配置及 API 实现约定。

主要职责：

- 校验并保存服务器连接、平台账号、发现规则、下载目录和并发设置；敏感凭据优先保存在系统凭据库，配置读取只返回摘要。
- 向远端 `backend/` 认证读取历史、同步记录和提交跟踪申请，持久化缓存、游标与提交队列。
- 使用留在本机的 Cookie 直接访问平台，执行分页发现、新投稿规则，以及后续的视频下载和评论保存。
- 独立调度和恢复本地任务。网页关闭或刷新不取消已接收任务；Agent 停止后本地界面及 API 不可用，重启后从持久化状态恢复。

本地通信与凭据边界遵循统一设计的 [运行方式与协作关系](../README.md#运行方式与协作关系)，可靠同步和任务恢复遵循 [离线、重启与同步](../README.md#离线重启与同步)。具体接口与会话建立协议在实现时确定。
