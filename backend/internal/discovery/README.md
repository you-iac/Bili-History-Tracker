# discovery 模块

负责作者视频融合、当前管理员关注过滤、统一分页及显式导入任务。不解释平台合集或原始业务码。包入口见 [service.go](service.go)，整体设计见 [作者视频设计](../../../docs/video-discovery.md)。

```text
+--------------------------+
| admin                    |
| 视频页 / 添加 / 查询进度 |
+--------------------------+
              |
              | 调用用例
              v
+--------------------------+    本地记录与关注状态   +--------------------------+
| service.go               | --------------------->  | storage                  |
| 合并 / 去重 / 过滤 / 分页|                         | 稳定续页 / 批量读取      |
+--------------------------+                         +--------------------------+
              |
              | 作者视频能力 / 已选视频导入
              v
+--------------------------+
| tracker / source         |
| 分发平台 / 校验归属入库  |
+--------------------------+
```

结果沿调用链返回；`jobs.go` 处理已经发现和后续发现的全部视频，复用同一 `IngestVideo` 写入用例。

- 默认视频页 30 条，上限 100；单次显式选择最多 100 个，添加全部不依赖前端加载所有页。
- 当前进程最多各保留 64 个会话和任务，20 分钟过期；发现最多 1000 步及约 10000 个视频，超限返回不完整，成功结果保留。
- 每次异步推进最多 8 步，达到下一批结果后暂停；空页且仍在发现时保留续页，重复平台游标返回错误。
- 导入任务之间串行处理单视频，排队及网络操作支持取消；失败恢复只处理失败与未完成项。
- 相同任务范围幂等复用，取消不会回滚成功项；会话和进度未持久化，服务重启后需重新加载。
- `Reader` 是本地读取边界；未来多用户在此独立计算个人订阅，避免按全局跟踪误过滤。

验证见 [service_test.go](service_test.go)，HTTP 闭环见 [admin/discovery_test.go](../admin/discovery_test.go)。
